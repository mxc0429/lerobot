## 抓取技巧

### 1. 正确的抓取姿态

```
推荐姿态：
- 从上方或侧面接近立方体
- 夹爪与立方体表面垂直
- 夹爪中心对准立方体中心
```

### 2. 抓取步骤

#### 步骤1: 接近
```
- 将机械臂移动到立方体上方
- 保持夹爪张开
- 高度略高于立方体（约5-10cm）
```

#### 步骤2: 下降
```
- 缓慢下降机械臂
- 确保夹爪对准立方体
- 下降到夹爪中心与立方体中心对齐
```

#### 步骤3: 夹取
```
- 缓慢闭合夹爪
- 确保两侧夹爪同时接触立方体
- 夹紧但不要过度用力
```

#### 步骤4: 抬起
```
- 缓慢抬起机械臂
- 保持夹爪闭合状态
- 观察立方体是否稳定
```

### 3. 常见问题和解决方法

#### 问题1: 立方体滑落

**原因**:
- 夹爪没有完全闭合
- 抓取角度不对
- 抬起速度太快

**解决方法**:
```bash
# 使用更小的立方体
python examples/so101_sim/s101_leader_to_sim.py --cube-size 0.02

# 使用更近的距离
python examples/so101_sim/s101_leader_to_sim.py --cube-distance 0.15

# 组合使用
python examples/so101_sim/s101_leader_to_sim.py --cube-size 0.02 --cube-distance 0.15
```

**操作建议**:
- 确保gripper关节值接近最大值（完全闭合）
- 从正上方垂直抓取
- 抬起时保持缓慢平稳

#### 问题2: 夹爪夹不住

**原因**:
- 立方体太大
- 夹爪开合角度不够

**解决方法**:
- 使用更小的立方体（2cm或2.5cm）
- 检查gripper关节是否能完全闭合

#### 问题3: 立方体被推走

**原因**:
- 接近速度太快
- 角度不对

**解决方法**:
- 从正上方接近
- 缓慢移动
- 确保夹爪完全张开
