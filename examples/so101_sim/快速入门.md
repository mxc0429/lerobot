# SO101多相机遥操作系统 - 快速入门

## 🚀 5分钟快速开始

### 第一步：测试显示系统（无需硬件）

首先测试显示系统是否正常工作，这一步**不需要真实机械臂**：

```bash
# Windows
python examples\so101_sim\multi_camera_display_test.py

# Linux/Mac
python examples/so101_sim/multi_camera_display_test.py
```

**预期效果**：
- ✅ 弹出一个窗口，显示三个相机视角
- ✅ 机械臂在仿真中随机移动
- ✅ 左上角显示相机名称（绿色）
- ✅ 右上角显示FPS（黄色）
- ✅ 左下角显示时间戳
- ✅ 右下角显示连接状态

**测试键盘控制**：
- 按 `p` → 暂停/继续（中央会显示"PAUSED"）
- 按 `r` → 重置环境（机械臂回到初始位置）
- 按 `s` → 保存截图（保存到 `snapshots/` 目录）
- 按 `q` → 退出程序

### 第二步：连接真实机械臂

#### Windows系统

1. **找到串口号**
   - 打开"设备管理器"
   - 展开"端口(COM和LPT)"
   - 找到你的设备，记下COM号（例如：COM3）

2. **运行遥操作程序**
   ```bash
   python examples\so101_sim\multi_camera_teleop.py --port COM3
   ```

#### Linux系统

1. **找到串口**
   ```bash
   ls /dev/tty* | grep -E "(ACM|USB)"
   ```
   通常是 `/dev/ttyACM0` 或 `/dev/ttyUSB0`

2. **设置串口权限（首次使用）**
   ```bash
   sudo usermod -a -G dialout $USER
   ```
   然后**注销并重新登录**

3. **运行遥操作程序**
   ```bash
   python examples/so101_sim/multi_camera_teleop.py --port /dev/ttyACM0
   ```

#### Mac系统

1. **找到串口**
   ```bash
   ls /dev/tty.* | grep usb
   ```
   通常是 `/dev/tty.usbmodem*` 或 `/dev/tty.usbserial*`

2. **运行遥操作程序**
   ```bash
   python examples/so101_sim/multi_camera_teleop.py --port /dev/tty.usbmodem14201
   ```

### 第三步：首次校准

第一次连接Leader机械臂时，系统会自动进行校准：

1. 按照屏幕提示移动机械臂到各个极限位置
2. 校准完成后，数据会自动保存
3. 下次使用时可以跳过校准：

```bash
python examples/so101_sim/multi_camera_teleop.py \
    --port COM3 \
    --skip_calibration
```

## 🔧 常见问题解决

### 问题1：找不到串口

**症状**：
```
错误: No such file or directory: '/dev/ttyACM0'
```

**解决方法**：

Windows:
```powershell
# PowerShell中运行
Get-WmiObject Win32_SerialPort | Select-Object Name,DeviceID
```

Linux:
```bash
ls /dev/tty* | grep -E "(ACM|USB)"
```

Mac:
```bash
ls /dev/tty.* | grep usb
```

### 问题2：权限被拒绝（Linux）

**症状**：
```
错误: Permission denied: '/dev/ttyACM0'
```

**解决方法**：
```bash
# 将当前用户添加到dialout组
sudo usermod -a -G dialout $USER

# 注销并重新登录，或者重启电脑
```

### 问题3：显示窗口卡顿

**症状**：FPS显示小于5

**解决方法**：使用低性能模式
```bash
python examples/so101_sim/multi_camera_teleop.py \
    --port COM3 \
    --camera_width 160 \
    --camera_height 120 \
    --display_fps 5 \
    --no_overlays
```

### 问题4：Leader机械臂连接失败

**症状**：
```
错误: Leader连接失败
```

**检查清单**：
- [ ] USB线已正确连接
- [ ] 机械臂已上电
- [ ] 串口号正确（COM3、/dev/ttyACM0等）
- [ ] 驱动已安装（Windows需要）
- [ ] 权限已设置（Linux需要）
- [ ] 没有其他程序占用串口

### 问题5：相机显示黑屏

**症状**：相机视图全黑或显示 "Camera not found"

**解决方法**：
1. 使用默认场景（不指定 `--xml_path`）
2. 检查MuJoCo XML文件中是否定义了相机
3. 确认相机名称正确（top_cam、wrist_cam、right_cam）
